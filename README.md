# Carclub.az

Прокат автомобилей в Баку. Сайт переписан с WordPress (Elementor + WPML) на
обычный PHP без базы данных: весь контент лежит в JSON, редактируется через
собственную админ-панель.

Четыре языка: **EN** (по умолчанию), **AZ**, **RU**, **AR** (с полной
поддержкой RTL).

---

## Запуск локально

```bash
php -S 127.0.0.1:8031 router.php
```

Сайт: <http://127.0.0.1:8031/> · Админка: <http://127.0.0.1:8031/admin/>

Данные для первого входа создаются автоматически при первом обращении к
админке и записываются в `storage/admin-password.txt` — после первого входа
смените пароль в разделе «Мой профиль» и удалите этот файл.

Учётные записи живут в `storage/admin-users.json` и в репозиторий не входят,
поэтому на сервере пароль свой, а не тот, что на рабочей машине.

**Если пароль потерян.** Положите рядом с данными файл
`storage/admin-reset.txt` (через файловый менеджер хостинга или по FTP):

```
admin@carclub.az:новый-пароль-от-8-знаков
```

При следующей попытке входа пароль применится, а файл удалится. Папка
`storage` закрыта от обращений по HTTP, так что сделать это может только тот,
у кого есть доступ к файлам сайта. Можно указать и просто пароль без адреса —
тогда он применится к первой учётной записи.

## Структура

```
index.php              Единая точка входа: разбор URL, язык, страница
router.php             Роутер для встроенного сервера PHP
.htaccess              ЧПУ, редиректы со старых адресов WP, кеш, защита папок

config/site.php        Значения по умолчанию: языки, контакты, контент 4 языков
storage/
  site.json            Что изменено в админке (перекрывает config)
  cars.json            Автопарк
  messages.json        Заявки с сайта
  admin-users.json     Пользователи админки          (не в git)
  login-throttle.json  Защита от перебора паролей     (не в git)

includes/
  functions.php        Ядро: конфиг, языки, URL, машины, форма, SEO
  i18n.php             Строки интерфейса на 4 языках
  icons.php            Инлайн-SVG иконки
  header.php footer.php socials.php cta.php form.php car-card.php

pages/
  home.php cars.php car.php about.php contact.php 404.php

admin/
  lib.php              Хранилище, авторизация, CSRF, загрузка файлов, вёрстка
  index.php            Все разделы панели

assets/
  css/style.css        Стили сайта (адаптив + RTL)
  js/main.js           Меню, фильтры, галерея, лайтбокс, валидация
  img/                 Логотип, фото автомобилей, логотипы марок, загрузки

html/                  Статическая копия сайта (см. ниже)
tools/build-static.py  Скрипт, который её собирает
```

## Адреса страниц

Адреса сохранены от старого WordPress, поэтому внешние ссылки и позиции в
поиске не теряются:

| Страница    | EN                     | AZ / RU / AR                    |
|-------------|------------------------|---------------------------------|
| Главная     | `/`                    | `/az/`, `/ru/`, `/ar/`          |
| Автомобили  | `/masinlar/`           | `/az/masinlar/` и т. д.         |
| О нас       | `/haqqimizda/`         | `/az/haqqimizda/` и т. д.       |
| Контакты    | `/elaqe/`              | `/az/elaqe/` и т. д.            |
| Автомобиль  | `/toyota-camry-2022/`  | `/az/toyota-camry-2022/` и т. д.|

Старые адреса `/wp-content/uploads/...` и `/category/...` перенаправляются
через `.htaccess`.

## Админ-панель

`/admin/` — те же принципы, что и в панели tce.az: файловое хранилище,
роли, защита от перебора пароля, CSRF на каждой форме.

| Раздел              | Что делает                                                        |
|---------------------|-------------------------------------------------------------------|
| Обзор               | Счётчики и последние заявки                                       |
| Автомобили          | Добавить/изменить/скрыть, характеристики, фото, обложка, порядок  |
| Главная страница    | Первый экран, показатели, преимущества, призыв — по каждому языку |
| Тексты страниц      | «О нас», «Автомобили», «Контакты», подвал — по каждому языку      |
| Изображения         | Загрузка файлов в `assets/img/uploads`                            |
| Контакты и соцсети  | Телефоны, WhatsApp, почта, Instagram/TikTok/Facebook, карта       |
| SEO                 | Title и description каждой страницы на каждом языке               |
| Заявки с сайта      | Просмотр, отметка «прочитано», ответ в WhatsApp, удаление         |
| Настройки           | Название, почта уведомлений, фоновые изображения, GA, число авто  |
| Безопасность        | Ключи Cloudflare Turnstile (только для администратора)             |
| Пользователи        | Администраторы и редакторы (только для администратора)            |
| Мой профиль         | Имя, email, смена пароля                                          |

Роли: **администратор** видит всё, **редактор** — всё, кроме «Пользователей»
и «Настроек».

### Как это хранится

`config/site.php` содержит значения по умолчанию, админка пишет только
изменённое в `storage/site.json`, и при загрузке они объединяются вглубь.
Обновление кода не затирает контент, а сброс сводится к удалению ключа
из `storage/site.json`.

## Статическая версия

`html/` — обычный HTML-снимок всего сайта: 4 языка × (главная, автомобили,
о нас, контакты, 404, 10 карточек автомобилей) = 60 файлов. Открывается прямо
с диска — `html/index.html`.

Раскладка повторяет боевую: английская версия лежит в корне снимка,
остальные языки — в своих папках.

```
html/index.html      главная (EN)      html/az/index.html
html/cars.html       автомобили        html/az/cars.html
html/about.html      о нас             html/ru/…  html/ar/…
html/contact.html    контакты
html/car-<slug>.html карточка автомобиля
```

Кнопка формы в снимке работает: она открывает WhatsApp с заполненной
заявкой. Сохранения заявки в админку, разумеется, не происходит — для
этого нужен PHP.

Пересобрать после правок контента:

```bash
php -S 127.0.0.1:8031 router.php
python tools/build-static.py
```

## Что изменилось по сравнению со старым сайтом

- Убраны WordPress, Elementor, WPML, 20+ плагинов и база данных.
- Каталог автомобилей чистый: в старой версии он был забит спамом после
  взлома (страницы про казино в разделе «Машины»).
- Русская версия была переведена частично («Send request», «About us»,
  «Free delivery» оставались на английском) — теперь переведена целиком.
- Иконка Instagram в шапке вела на WhatsApp. Теперь ссылка задаётся в
  админке отдельно и, пока она пустая, иконка не показывается.
- Добавлены: фильтры в каталоге по кузову и марке, галерея с лайтбоксом и
  свайпом, характеристики автомобиля, похожие автомобили, hreflang, Open
  Graph, разметка schema.org, honeypot и CSRF в формах.
- Вёрстка адаптивная, RTL для арабского, тёмная тема бренда (чёрный + золото,
  Montserrat).

## Скорость

Фотографии отдаются в трёх размерах (400, 800, 1400 px) и двух форматах —
WebP и JPEG. Браузер сам берёт подходящий через `srcset`, старые браузеры
получают JPEG. В шаблонах за это отвечает `picture()` из
`includes/functions.php`; если вариантов нет, он просто выводит исходный
файл, так что сайт не сломается.

Шрифт Montserrat лежит в `assets/fonts` и подключается с того же домена:
никакого обращения к `fonts.googleapis.com`, на одно DNS-разрешение и одно
TLS-рукопожатие меньше до первого текста. Начертания 400 и 800 нужного
языку набора предзагружаются.

Каталог до оптимизации весил 2.2 МБ, после — около 1.3 МБ, и это ещё до
gzip, который включён в `.htaccess`.

После добавления новых фотографий нужно пересобрать варианты:

```bash
python tools/optimize-images.py        # --force пересоздаёт существующие
```

Шрифты обновляются отдельно и обычно не требуют внимания:

```bash
python tools/fetch-fonts.py
```

## Развёртывание

1. Залить всё, кроме `html/` (он нужен только как макет), в корень домена.
2. Проверить, что папка `storage/` доступна PHP на запись.
3. Открыть `/admin/`, войти, сменить пароль, удалить
   `storage/admin-password.txt`.
4. В «Настройках» указать адрес сайта — он попадёт в canonical и Open Graph.
